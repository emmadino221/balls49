📏 Gap Playing Windows
Market Loss level / auto gap

The loss level measures how far apart that many losses in a row have been. The average gap, rounded up, sets a playing window: every eligible draw in it is played, then the next window opens. Auto picks a better-supported level at each window end. SKIPs use up a draw without a bet. Saved with Save Settings, while automation is stopped.
